Privacy Policy

Last updated: 26 October 2026

This policy covers two things: this public website, and Fault & Folly, the private internal application the channel owner uses to publish and manage videos on the Fault & Folly YouTube channel.

1. This website

  • This is a static website. It has no accounts, sign-in, forms or comments.
  • It sets no cookies and uses no analytics, advertising or tracking tools.
  • It loads no third-party scripts, fonts or other external resources.
  • The site is hosted on GitHub Pages. Like any web host, GitHub may process technical information such as your IP address to deliver and secure the site. See the GitHub Privacy Statement.
  • If you email us, we receive your email address and message and use them only to reply.

2. The Fault & Folly publishing application

The application is an internal tool, not a public service. It is used only by the owner of the Fault & Folly channel to manage that channel. Nobody else signs in to it, and it does not access any other person's Google or YouTube account.

The channel owner signs in with Google OAuth and authorizes the application to access the channel's own YouTube account. The application requests these permissions:

  • https://www.googleapis.com/auth/youtube.upload: upload new episodes to the channel (as private videos first) and set their thumbnails.
  • https://www.googleapis.com/auth/youtube.readonly: read information about the channel and its videos, for example to confirm an upload and check its processing and privacy status. It is also used to read public video information on YouTube for episode research.
  • https://www.googleapis.com/auth/youtube.force-ssl: change a video's privacy status or scheduled publication time. This is used only after the owner has approved the video for publication.
  • https://www.googleapis.com/auth/yt-analytics.readonly: read aggregate performance reports for the channel's own videos, such as views, watch time, audience retention and traffic sources.

YouTube Analytics reports are aggregate statistics. The application does not receive or store the identity of individual viewers, and it does not read comments, subscriber lists or private messages.

3. How the information is used

  • To upload, schedule and publish the channel's own videos.
  • To send the channel owner private performance summaries for the channel's own videos.
  • To help plan future episodes. Aggregate performance figures for the channel's own videos may be included in requests to a third-party AI text service that the application uses to draft topic ideas.

Information received from Google APIs is not sold, not used for advertising, and not shared with anyone except as described above.

4. Storage and security

  • OAuth authorization credentials are stored only on a private server operated for the channel, in a configuration file that only the application can read.
  • They are never published on this website, never included in source code, and never shared publicly.
  • Performance snapshots for the channel's own videos are stored in a private database on the same server.

5. Revoking access

The channel owner can revoke the application's access at any time on the Google Account Third-party apps & services page. After access is revoked, the stored credentials stop working and the application can no longer reach the YouTube account. Stored credentials and performance snapshots can be deleted from the private server at any time.

6. Google and YouTube

The application uses YouTube API Services. By using YouTube you agree to the YouTube Terms of Service, and Google handles your information under the Google Privacy Policy.

7. Changes

If what the website or the application does with information changes, we will update this page and its date.
